# Experiment code

The write-ups in `docs/experiments/` record what was measured and what it meant.
This holds the code that produced them, so a result can be re-run, audited, or
corrected rather than only re-read.

**Why this exists.** For the first 37 experiments it did not: 39 write-ups
existed and none of their code was version-controlled. That matters more here
than in most projects, because the recurring defect in this repository is a
*broken instrument* rather than a wrong idea — the harness that never exchanged
teams (0031), the module-global weight that faked a null (0033), the pool
generated by the wrong format (0024), the fork that recorded an unusable seed.
Each was found by re-reading code, and twice a published result had to be
withdrawn (0029) or overturned (0027). Re-running is the fix for both, and the
code to re-run with was gone.

## Running them

Everything is run **from the repository root**, because the scripts reach for
`data/replays`, `data/dex.json` and `data/pool-eval.txt` by relative path:

```bash
python experiments/0039-guessing-the-opponent/collect.py out.json 200 8 24
python experiments/0039-guessing-the-opponent/report.py out.json
```

Collection scripts write JSON; report scripts read it and print. They are split
because collection takes tens of minutes and analysis gets re-run often — and
because 0038 found a bias in its own analysis after collection was finished,
which would have meant re-running everything had they been one script.

## What they need, and what you will not get from a clean clone

`data/replays/` is deliberately not in the repository: the replay logs carry no
licence, so this project holds a corpus for local research and never
redistributes it (see the note in `.gitignore`). `data/pool-eval.txt` is derived
from it and inherits the same constraint. So these scripts run against a local
corpus you collected with `data/collect.py`; without one they will not start.

**A number reproduced on a different corpus is not the same number.** The pool
is frozen at `data/pool-eval.txt` precisely so that re-running a comparison does
not silently change the teams underneath it — an unseeded pool once made two
runs of the Mega comparison disagree in direction.

## Convention

One directory per experiment, named for the write-up it belongs to. Scripts are
committed **as they were run**. If a defect is found afterwards it is recorded
in the write-up and, where the fix would change what was measured, left in the
code with a comment saying so — a script quietly improved after publication no
longer matches the result it produced.
